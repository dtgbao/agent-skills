Cited criterion text (from requirements.md):
- 1.1: WHEN a shopper buys a Gift_Card with a value of 10–500 dollars, THE Shop_API SHALL charge the Payment_Provider and create an `active` Gift_Card with that balance.
- 1.2: WHEN a Gift_Card is created, THE Shop_API SHALL return its 16-character code.
- 1.3: IF the Payment_Provider declines the charge, THEN THE Shop_API SHALL return HTTP 402 with error `payment_declined` and create no Gift_Card.
- 1.4: IF the purchase value is outside 10–500 dollars or not a whole number of dollars, THEN THE Shop_API SHALL return HTTP 400 with error `invalid_amount` and charge nothing.
- 1.5: IF the Payment_Provider charge fails for a reason other than a decline, THEN THE Shop_API SHALL return HTTP 502 with error `payment_failed` and create no Gift_Card.
- 2.2: THE Shop_API SHALL return the response to a redemption request within 2 seconds.
- 2.4: IF the code does not match any Gift_Card, THEN THE Shop_API SHALL return HTTP 404 with error `unknown_card`.
- 3.1: WHEN a staff member voids a Gift_Card through the Merchant_Portal, THE Shop_API SHALL set the Gift_Card status to `void`.
- 3.2: WHILE a Gift_Card is `void`, THE Shop_API SHALL reject redemption with HTTP 409 and error `card_void`, whatever the Cart subtotal.
- 3.3: IF a void request comes from an Actor that is not staff, THEN THE Shop_API SHALL return HTTP 403 with error `forbidden` and leave the Gift_Card status unchanged.
- 5.5: IF a purchase or redemption request has no `ctx["actor"]`, THEN THE Shop_API SHALL return HTTP 401 with error `actor_required` before any amount, code or balance check, and change nothing.
