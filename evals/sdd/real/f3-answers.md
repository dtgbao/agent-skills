# f3 owner answers

Read this file only when you ask the user a question. Answer only that question.

- Tiers: 10–19 units of one product: 10 % off that product's line. 20 or more units: 15 % off that line. Fewer than 10: no change.
- Count: the units of each product (each cart line) separately, not the whole cart.
- Rounding: compute each line total, apply the percent, and round the line down to whole cents. Do not round each unit.
- Tiers do not stack: a line gets one tier only.
- Other rules: none (no cap, all products, no expiry).
