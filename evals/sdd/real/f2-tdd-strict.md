## Script (f2, strict tdd baseline, no plugin)

Follow the `tdd` skill exactly: vertical slices. One test, then the code that makes it pass, then the next test. Never write the next test before the current test is green. Run the test after you write it (it must fail for the right reason) and after you write the code.

Feature text: the content of `f2-feature.md` in this folder, word for word.

Commands:
1. Invoke the `tdd` skill and build the feature text, one test at a time.

Answers:
- Any question to the user: pick the most conservative concrete option, and log it in `eval/notes.md`.
