# Sections

This file defines the catalog sections and filename prefixes.

---

## 1. Creational Patterns (create)

**Purpose:** Control object creation so clients depend on stable contracts rather than concrete construction details.

## 2. Structural Patterns (struct)

**Purpose:** Compose classes and objects into larger structures while keeping those structures flexible.

## 3. Behavioral Patterns (behavior)

**Purpose:** Distribute algorithms and responsibilities while reducing coupling between collaborating objects.
